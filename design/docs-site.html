Why MXFrame

Write it like Polars. Run it in Mojo.

A lazy DataFrame and SQL engine compiled ahead of time with Mojo. On TPC-H SF10 it runs the 22 queries in 3.15 s, against 5.08 s for DuckDB and 14.40 s for Polars.

What you're looking atEvery number on this site links to the benchmark file it came from.
quickstart.py
import mxframe as mx
lf = mx.scan_parquet("lineitem.parquet")
lf.filter(mx.col("l_shipdate") <= "1998-09-02")
  .groupby("l_returnflag")
  .agg(mx.col("l_quantity").sum())
  .compute()
# → a pyarrow Table, one row per return flag
