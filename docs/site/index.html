A DataFrame engine written in Mojo.
Polars-style API, faster than DuckDB on TPC-H SF10.

MXFrame builds a lazy query plan from Python (DataFrame calls or SQL), then runs the whole plan in one call into a native Mojo executor, on all your CPU cores. The GPU is there when you have one.

quickstart.py
# pip install "mxframe[runtime]"
import mxframe as mx

lf = mx.scan_parquet("lineitem.parquet")
out = (lf.filter(mx.col("l_quantity") < 24)
         .groupby("l_returnflag")
         .agg(mx.col("l_extendedprice").sum().alias("revenue"))
         .sort("l_returnflag")
         .compute(device="cpu"))   # a pyarrow Table
